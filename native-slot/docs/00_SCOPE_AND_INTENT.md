# 0. 项目范围与使用说明

## 0.1 项目性质

本目录是一套**自有虚拟机集群槽位服务**的维护与架构迁移规格。

槽位服务已经在生产环境中运行，当前组件运行在与目标不同的架构上。
迁移目标是提供 ARM64 原生实现，使同一套服务可以在 ARM64 主机上
直接运行。

## 0.2 工作内容

| 项 | 说明 |
| --- | --- |
| 输入 | 现有部署的功能、接口与运行行为 |
| 产出 | 可供重新实现的接口规格与验收标准 |
| 范围 | 自有组件的进程模型、配置、协议与错误处理 |
| 不包含 | 任何第三方系统的未授权访问 |

具体交付物见 `README.md`。

## 0.3 安全与合规边界

本文档及其配套规格遵循以下边界：

1. **自有环境**：所有组件、配置、凭据与测试环境均由项目所有者管理；
2. **不包含凭据**：文档只描述凭据文件的**结构**，不包含任何真实密钥；
3. **不使用生产流量做实验**：验收测试使用本地 mock 上游，不向真实
   服务发送测试请求；
4. **不改变现有服务行为**：迁移前后对外接口保持一致，不引入新的
   访问能力；
5. **可核对**：所有结论标注确认状态，未确认项单独列出，不做推测性
   实现。

## 0.4 文档用途

本目录用于：

- 指导 ARM64 版本的开发；
- 作为开发人员与 AI 助手之间的规格输入；
- 作为迁移验收的判定依据。

阅读时请以 `README.md` 的顺序为准。文档中的「上游」指本项目部署
所连接的模型服务端点，不存在对其他系统的访问意图。

## 0.5 术语

| 术语 | 含义 |
| --- | --- |
| 槽位服务 | 本项目部署的推理请求转发服务 |
| 内核 | 槽位服务的调度进程 |
| CLI 宿主 | 槽位服务中负责上游调用的子进程 |
| 上游 | 模型服务端点 |
| 迁移 | 从现有构建切换到 ARM64 原生构建 |
