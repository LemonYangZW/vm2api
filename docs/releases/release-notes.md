# 发布记录

### 2026-10-21

- Oracle 更新只自动构建并验证 ARM64 镜像，支持构建缓存；完整测试与三层差分按需手动执行。
- ARM64 镜像加入原生 crag 内核，本机 Docker crag 槽自动选用；官方 cc-node 继续通过 QEMU 运行。
- 同步上游 1.3.206：官方登录链接支持跨终端输出提取，可复制、打开授权页并回填授权码；统一 OAuth 方式顺序，遥测同步默认显示关闭。
- 同步上游 1.3.205：缓存标记使用设置中的 TTL，默认 1 小时，显式 5 分钟保持不变。
- ARM64 原生槽保留新版官方提示和调用方时区，面板登录入口继续复用同一份凭据。
- 合入实验性 macOS 原生节点、后台备份和面板用量显示修正。macOS 节点仍需另备原生产物，功能范围见 [MACOS_NODE.md](../MACOS_NODE.md)。

此前版本与上游完整升级说明见 [CHANGELOG.md](../../CHANGELOG.md)。
